# Databázový klient pro macOS

Otevřete [projekt ConnectionBrowser](ConnectionBrowser.xcodeproj) v Xcode a zvolte schéma `ConnectionBrowser` a cíl `My Mac`. Zkratka ⌘R spustí okno se dvěma skupinami ukázkových spojení. Zkratka ⌘U spustí XCUITest, který sbalí a znovu rozbalí skupinu Katalog. Snímky obou stavů najdete v přílohách testu.
